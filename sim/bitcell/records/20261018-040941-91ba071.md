## Limits of this record

- Graded margin is `eye_snm`. The pinned extractor over-reads (filed as 2AMLogic/gf180-sram#213); at tt / 1.98 V / 25 C read, `eye_snm` 0.4419 V matches an independent series-noise-source SPICE probe (0.4410 V, single local ngspice run) while the pinned script says 0.572 V.
- Write margin is the 2 ns write-trip ladder (resolution VDD/32), not gf180-sram's bisection (`klt sim` owns the `.control` block). The worst corner is the thinnest margin in the set; **no Monte Carlo was run on write margin**, so a mismatch-driven write failure is not excluded.
- Monte Carlo covers read and hold SNM only: 60 samples at 6 points (tt, sf, fs `_mm` sections x 1.62 / 1.98 V x 125 C, the hot corner where both margins are lowest in the deterministic table), not the full 45. The "deterministic corner" column is the matching non-mismatch corner, a consistency check, not gf180-sram's exact mismatch-off rerun. No negative control and no `klt yield` report were produced, so the gf180-sram statistical-evidence recipe is not fully met; sigma is estimated from 60 draws.
- Read/hold use decoupled half-cell fixtures whose sizes come from the same `sizing.json` as the schematic and layout; they model no layout parasitics (no PEX).
- The fleet image PDK is open_pdks c6d73a3; requests set `options.stage_model_inputs` so the models are shipped from the repo-pinned f6eeac7 install (worker `pdk.models_staged` is reported in the gz reports).
